Vue d'ensemble

Ce corpus couvre 100 % du référentiel officiel CCA-F. Il est conçu pour le retrieval practice : teste-toi fiches fermées d'abord, puis lis pour combler tes lacunes, et explique à voix haute pourquoi chaque distracteur est faux. La relecture passive crée une illusion de maîtrise — elle ne suffit pas.

Comment réviser — méthode evidence-based :
  1. Diagnostic : réponds aux auto-évaluations des 5 fiches de domaine, fiches fermées → ton profil ci-dessous se remplit et te donne l'ordre de révision.
  2. Par domaine (ordre poids × faiblesse) : teste-toi d'abord, puis lis pour combler, débriefe chaque distracteur — dis à voix haute pourquoi chacun est faux.
  3. Volume : les 112 QCM corrigés, dont les 12 exemples officiels du guide. Vise ≥ 85 % au 2e passage, aucun domaine sous 75 %.
  4. Dernière ligne droite : relis seulement tes erreurs + les cheat sheets & arbres de décision.

Méthode complète (5 règles sourcées, journal d'erreurs) → Stratégie d'examen.

Ressources officielles — quoi suivre, quoi sauter

Le guide d'examen est la seule source qui définit ce qui est testé. Lisez-le en entier avant de programmer votre examen — ce corpus le résume, il ne le remplace pas.

Guide officiel CCA-F (PDF, 614 Ko) — version 1.0, effective juillet 2026, code d'examen CCAR-F. Source : la page de certification sur l'Anthropic Partner Academy, qui sert la version faisant foi si elle est révisée.

Les 7 « prep courses » ne sont pas le référentiel. Ce sont des cours d'apprentissage qui débordent largement du périmètre de l'examen. Les suivre intégralement, c'est passer des heures sur du hors-scope. Voici ce qu'ils valent réellement pour le CCA-F.

Les 6 scénarios (4 tirés au sort)

  1. Customer Support Resolution Agent — agents traitant retours, billing, account issues avec 80%+ first-contact resolution
  2. Code Generation with Claude Code — configuration d'équipe, slash commands, CLAUDE.md, plan mode
  3. Multi-Agent Research System — coordinateur déléguant à subagents spécialisés (search, analyze, synthesize)
  4. Developer Productivity with Claude — outils aidant les devs à naviguer codebases, automatiser via builtin tools + MCP
  5. Claude Code in CI/CD — code review automatisé, test generation, PR feedback avec session isolation
  6. Structured Data Extraction — extraction de docs non structurés avec JSON schéma validation et batch
